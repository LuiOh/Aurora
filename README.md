# Aurora

텍스트 편집, 두 파일 비교, 마크다운 업무 노트를 한 앱에서 쓰는 도구입니다. Notepad++와 Beyond Compare를 대신하려고 만들었고, 노트 기능은 옵시디언처럼 `[[링크]]`, 백링크, 그래프를 지원합니다. VS Code와 같은 편집 엔진(Monaco)을 Electron으로 감쌌고 맥, 윈도우, 웹 브라우저에서 씁니다.

노트는 평범한 `.md` 파일이라 옵시디언, 타이포라, 깃허브에서도 그대로 열립니다.

## 설치

[Releases](https://github.com/LuiOh/Aurora/releases)에서 내려받습니다.

- **맥 (Apple Silicon)**: `Aurora-0.1.0-arm64.dmg`를 열어 Aurora를 응용 프로그램 폴더로 끌어다 놓습니다.
- **윈도우**: `Aurora.Setup.0.1.0.exe`로 설치하거나, 설치 없이 쓰려면 `Aurora-0.1.0-win.zip`(ARM PC는 `arm64-win.zip`)을 풀어 실행합니다.

코드 서명을 하지 않은 빌드라 처음 한 번은 경고가 뜹니다. 맥은 응용 프로그램 폴더에서 Aurora를 오른쪽 클릭해 "열기"를 누릅니다. 그래도 열리지 않으면 터미널에서 `xattr -dr com.apple.quarantine /Applications/Aurora.app`을 실행합니다. 윈도우는 SmartScreen 경고에서 "추가 정보"를 누르고 "실행"을 누릅니다.

## 빠른 시작

1. Aurora를 켜면 왼쪽에 노트 사이드바, 오른쪽에 마크다운 미리보기가 열려 있습니다.
2. 사이드바의 **오늘** 버튼(또는 ⌘T)을 누르면 노트 폴더를 고르라고 묻습니다. 노트를 모아 둘 폴더를 하나 고릅니다.
3. 오늘 날짜 노트가 열립니다. "어제 한 일", "오늘 할 일", "이슈", "메모" 칸에 적고 ⌘S로 저장합니다.
4. 다음 날 ⌘T를 누르면, 전날 "오늘 할 일"에서 체크한 일은 "어제 한 일"로, 체크하지 않은 일은 "오늘 할 일"로 넘어옵니다.

윈도우에서는 ⌘ 대신 Ctrl, ⌥ 대신 Alt를 누릅니다. 윈도우에는 메뉴 막대가 없으므로 탭 막대 맨 왼쪽의 ☰ 버튼으로 메뉴를 엽니다.

## 노트 쓰는 법

### 세 가지 노트

노트는 쓰임에 따라 세 가지로 나눠 쓰면 편합니다. 사이드바 **노트** 칸 맨 위의 버튼으로 만듭니다.

- **날짜 노트(+ 날짜)**: 그날 한 일과 할 일을 적는 업무 일지입니다. `daily/2026-10-20.md`처럼 날짜별로 쌓입니다. 달력에서 날짜를 눌러 그날 노트를 열 수도 있습니다.
- **주제 노트(+ 주제)**: 주제 하나를 계속 키워 가는 정리 노트입니다. 공부하거나 자료를 조사할 때 알게 된 것을 고쳐 쓰고 더해 갑니다. `주제/` 폴더에 `#주제` 태그와 요약·내용·관련 칸이 들어간 틀로 만들어집니다.
- **목차 노트(+ 목차)**: 주제 노트가 많아지면 관련 노트들을 링크로 모아 두는 지도입니다. `목차/` 폴더에 만들어집니다.

날짜 노트에 "[[바이닉 문진 서비스]] 개발"처럼 주제 링크만 달아 두면, 주제 노트를 열었을 때 백링크 칸에 그 주제를 다룬 날짜들이 모여 보입니다. 폴더 이름은 Notes 메뉴의 **노트 저장 위치…**에서 바꿉니다.

### 링크와 백링크

- 본문에 `[[`를 치면 노트 이름 후보가 뜹니다. 고르면 `[[노트 이름]]`이 들어갑니다.
- 링크를 ⌘클릭하거나 커서를 올리고 ⌘⌥Enter를 누르면 그 노트로 갑니다. 아직 없는 노트는 점선으로 보이고, 따라가면 새로 만들어집니다.
- `[[노트#제목]]`으로 노트 안의 제목에, `[[노트|보이는 이름]]`으로 다른 이름을 붙여 링크합니다.
- 사이드바 **백링크** 칸에는 지금 노트를 링크한 곳(링크된 언급)과, 링크 없이 이름만 적힌 곳(링크 안 된 언급)이 나옵니다.
- **그래프 보기(⌘⌥G)**로 노트들이 어떻게 이어졌는지 한눈에 봅니다. 노드를 누르면 그 노트가 열립니다.

### 태그와 할 일

- `#업무`, `#업무/회의`처럼 태그를 붙이면 사이드바 **태그** 칸에 태그별 노트 수가 나오고, 누르면 그 태그로 검색합니다.
- `- [ ] 할 일`처럼 체크박스를 쓰고 ⌘Enter로 체크합니다. 사이드바 **할 일** 칸에는 모든 노트의 안 한 일이 모이고, 거기서 바로 체크할 수 있습니다.

### 이미지·영상·파일 첨부

- 화면 캡처를 노트에서 ⌘V로 붙여 넣으면, 노트 파일이 있는 폴더 안에 `첨부` 폴더가 생기고 이미지가 저장됩니다. 노트에는 `![](<첨부/Pasted image ….png>)`가 들어갑니다.
- 영상, 오디오, PDF, 오피스 문서는 노트 편집기 위로 끌어다 놓으면 같은 방식으로 첨부됩니다.
- 미리보기에서 이미지는 보이고, 영상과 오디오는 그 자리에서 재생됩니다. 그 밖의 파일은 누르면 기본 앱으로 열립니다.
- 저장하지 않은 새 탭에도 붙여 넣을 수 있습니다. 탭을 저장할 때 첨부도 함께 저장됩니다.
- 링크가 노트 기준 상대 경로라서 노트와 `첨부` 폴더를 함께 옮기면 첨부도 따라갑니다.

### 찾기

- **빠르게 열기(⌘P)**: 노트 이름 몇 글자만 쳐도 찾습니다. ⇧Enter를 누르면 입력한 이름으로 새 노트를 만듭니다.
- **전체 검색(⌘⇧F)**: 공백으로 나눈 조건을 모두 만족하는 줄을 찾습니다. `tag:#업무`, `file:회의`, `path:주제`, `task-todo:`, `-제외어`, `"정확한 문구"`, `/정규식/`을 쓸 수 있습니다.

## 편집과 비교

- **탭 편집**: 파일을 창에 끌어다 놓거나 ⌘O로 엽니다. 저장하지 않은 탭은 이름 앞에 ●이 붙습니다. 파인더의 "다음으로 열기"나 탐색기의 "연결 프로그램"에서 `.md` 파일을 Aurora로 열 수도 있습니다.
- **열 선택과 멀티 커서**: ⌥⇧ 드래그로 열(박스) 선택을, ⌥ 클릭으로 커서 추가를 합니다.
- **번호 넣기(⌘⌥N)**: 커서마다, 또는 선택한 줄마다 번호를 넣습니다. 시작값, 증가값, 0 채우기를 고릅니다.
- **비교**: 다른 탭과(⌘⌥D), 클립보드와(⌘⌥V) 비교합니다. 원본 탭에서 ⌘1을 누르고 다른 탭에서 ⌘⇧C를 누르면 둘을 비교합니다. F7·⇧F7로 차이 사이를 옮겨 다니고, 공백·대소문자 무시를 켤 수 있습니다.
- **JSON·XML 정리(⌘⌥J, ⌘⌥X)**: 선택한 부분이 있으면 그 부분만, 없으면 문서 전체를 정리합니다. 숫자와 중복 키는 바꾸지 않습니다.

## 단축키

맥 기준 기본값입니다. 앱 메뉴의 **단축키 설정…(⌘,)**에서 모든 메뉴 기능의 단축키를 바꿀 수 있습니다.

- 파일: 새 탭 ⌘N, 열기 ⌘O, 저장 ⌘S, 다른 이름으로 저장 ⌘⇧S, 탭 닫기 ⌘W
- 편집: 찾기 ⌘F, 바꾸기 ⌘⌥F, 번호 넣기 ⌘⌥N, 줄 바꿈 ⌥Z
- 노트: 오늘 노트 ⌘T, 체크박스 ⌘Enter, 사이드바 ⌘B, 미리보기 ⌘⇧V
- 노트 찾기: 빠르게 열기 ⌘P, 전체 검색 ⌘⇧F, 링크 따라가기 ⌘⌥Enter, 그래프 ⌘⌥G
- 비교: 다른 탭과 ⌘⌥D, 클립보드와 ⌘⌥V, 원본 지정 ⌘1, 원본과 비교 ⌘⇧C, 다음·이전 차이 F7·⇧F7, 닫기 Esc
- 정리: JSON ⌘⌥J, XML ⌘⌥X

자세한 설명은 [사용설명서](docs/사용설명서.md)에 있습니다.

## 알아둘 점

- 노트 폴더 아래 모든 `.md` 파일을 읽어 색인합니다. `.`으로 시작하는 폴더(`.obsidian`, `.git`)와 `node_modules`는 건너뜁니다. 파일이 아주 많은 폴더(다운로드 폴더 등)를 노트 폴더로 잡으면 느려질 수 있습니다.
- 노트 폴더는 사이드바 아래 경로를 누르거나 Notes 메뉴의 **노트 폴더 바꾸기…**로 바꿉니다.
- 맥과 윈도우에서 함께 쓸 수 있도록 노트·폴더 이름에 `< > : " | ? *`는 쓰지 못하게 막습니다.
- 파일은 UTF-8로 읽고 씁니다. 화면 색은 시스템의 다크·라이트 모드를 따릅니다.
- 웹 버전은 크롬·엣지의 폴더 접근 기능으로 노트 폴더를 직접 읽고 씁니다. 다른 브라우저에서는 파일을 하나씩 열고 내려받기로 저장합니다.
- 예전 이름은 Quire, 그 전에는 TextBench입니다. 처음 실행할 때 예전 앱의 노트 폴더 설정과 단축키를 옮겨 옵니다.

## 개발

Node 20.19 이상이 필요합니다.

1. `npm install`로 의존성을 설치합니다. electron 바이너리가 받아지지 않았으면 `node node_modules/electron/install.js`를 한 번 실행합니다.
2. `npm run dev`로 개발 모드를 띄우고, `npm test`로 단위 테스트를 돌립니다.
3. `npm run build`로 타입 검사와 빌드를 합니다.
4. `npm run dist`로 맥 앱과 dmg를, `npm run dist:win`으로 윈도우 설치 파일과 zip을 `release/`에 만듭니다. 윈도우 빌드는 맥에서도 만들 수 있습니다.
5. `npm run dev:web`으로 웹 버전을 띄우고, `npm run build:web`으로 `dist/`에 올릴 파일을 만듭니다.
6. 아이콘은 `build/icon.svg`를 고친 뒤 `scripts/icons.sh`로 맥·윈도우·웹 아이콘을 다시 만듭니다.

구조는 다음과 같습니다.

- `electron/`: 메인 프로세스(창, 메뉴, 파일 입출력), preload, 명령·단축키 정의
- `src/main.ts`: 화면 진입점(탭, 비교, 노트, 명령 처리)
- `src/lib/`: 테스트할 수 있는 순수 로직(데일리 노트, 링크·검색·그래프, 첨부, 번호, JSON·XML 정리)
- `src/ui/`: 대화상자, 빠른 열기, 그래프 화면
- `src/web/`: 웹 버전의 파일 입출력
- `tests/`: vitest 단위 테스트
