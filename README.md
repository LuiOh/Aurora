# Aurora

텍스트 편집, 두 파일 비교, 마크다운 업무 노트를 한 앱에서 쓰는 도구입니다. Notepad++와 Beyond Compare를 대신하려고 만들었고, 노트 기능은 옵시디언처럼 `[[링크]]`, 백링크, 그래프를 지원합니다. VS Code와 같은 편집 엔진(Monaco)을 Electron으로 감쌌고 맥, 윈도우, 웹 브라우저에서 씁니다.

노트는 평범한 `.md` 파일이라 옵시디언, 타이포라, 깃허브에서도 그대로 열립니다.

## 설치

[Releases](https://github.com/LuiOh/Aurora/releases)에서 내려받습니다.

- **맥 (Apple Silicon)**: `Aurora-0.1.0-arm64.pkg`를 열어 설치합니다. Aurora가 응용 프로그램 폴더에 들어갑니다.
- **윈도우**: `Aurora.Setup.0.1.0.exe`로 설치합니다.

코드 서명을 하지 않은 빌드라 처음 한 번은 경고가 뜹니다. 맥은 설치 파일을 처음 열 때 막히면 시스템 설정 > 개인정보 보호 및 보안에서 "그래도 열기"를 누릅니다(macOS 14 이하는 설치 파일을 오른쪽 클릭해 "열기"). 설치 프로그램이 앱의 격리 표시를 지우므로 설치한 Aurora는 경고 없이 열립니다. 윈도우는 SmartScreen 경고에서 "추가 정보"를 누르고 "실행"을 누릅니다.

## 빠른 시작

1. Aurora를 켜면 왼쪽에 노트 사이드바, 오른쪽에 마크다운 미리보기가 열려 있습니다.
2. 사이드바의 **오늘** 버튼(또는 ⌘T)을 누르면 노트 폴더를 고르라고 묻습니다. 노트를 모아 둘 폴더를 하나 고릅니다.
3. 오늘 날짜 노트가 열립니다. "어제 한 일", "오늘 할 일", "이슈", "메모" 칸에 적고 ⌘S로 저장합니다.
4. 다음 날 ⌘T를 누르면, 전날 "오늘 할 일"에서 체크한 일은 "어제 한 일"로, 체크하지 않은 일은 "오늘 할 일"로 넘어옵니다.

윈도우에서는 ⌘ 대신 Ctrl, ⌥ 대신 Alt를 누릅니다. 윈도우에는 메뉴 막대가 없으므로 탭 막대 맨 왼쪽의 ☰ 버튼으로 메뉴를 엽니다.

## 노트 쓰는 법

### 세 가지 노트

노트는 쓰임에 따라 세 가지로 나눠 쓰면 편합니다. 사이드바 **노트** 칸 맨 위의 버튼으로 만듭니다.

- **날짜 노트(+ 날짜)**: 그날 한 일과 할 일을 적는 업무 일지입니다. `daily/2026-10-20.md`처럼 날짜별로 쌓입니다. 달력에서 날짜를 눌러 그날 노트를 열 수도 있습니다.
- **주제 노트(+ 주제)**: 주제 하나를 계속 키워 가는 정리 노트입니다. 공부하거나 자료를 조사할 때 알게 된 것을 고쳐 쓰고 더해 갑니다. `주제/` 폴더에 `#주제` 태그와 요약·내용·관련 칸이 들어간 틀로 만들어집니다.
- **목차 노트(+ 목차)**: 주제 노트가 많아지면 관련 노트들을 링크로 모아 두는 지도입니다. `목차/` 폴더에 만들어집니다.

날짜 노트에 "[[바이닉 문진 서비스]] 개발"처럼 주제 링크만 달아 두면, 주제 노트를 열었을 때 백링크 칸에 그 주제를 다룬 날짜들이 모여 보입니다. 폴더 이름은 Notes 메뉴의 **노트 저장 위치…**에서 바꿉니다.

### 새 파일 형식

- 사이드바 **노트** 칸의 **+ 날짜**, **+ 주제**, **+ 목차** 옆에 **+ 파일**이 있습니다. 이름을 넣고 **형식**에서 마크다운(.md), 텍스트(.txt), 웹 페이지(.html), CSS, 자바스크립트, JSON, CSV, XML, YAML, SQL, 셸 스크립트, 파이썬 중 하나를 고릅니다. 이름에 확장자를 치면 형식이 저절로 골라집니다.
- **+ 주제**와 **+ 목차**에서도 형식을 고를 수 있습니다. 마크다운이 아닌 파일은 빈 내용으로, html은 기본 페이지 뼈대로 시작합니다. 날짜 노트는 그대로 `.md`입니다.
- 빠르게 열기(⌘P)에서 이름에 확장자를 붙여 ⇧Enter를 누르면 그 형식의 파일을 만듭니다.
- 노트 폴더 안의 텍스트 파일(위 확장자와 htm, ts, yml, log, markdown)은 노트 목록, 빠르게 열기, 전체 검색에 나옵니다. `.md`가 아닌 파일은 1MB까지만 읽습니다. `[[링크]]`, 백링크, 태그, 할 일, 그래프는 마크다운 파일에만 해당합니다.
- 미리보기는 마크다운을 전처럼 보여 주고, html은 웹 페이지로(스크립트, 폼, style 태그는 걷어 냅니다), 그 밖의 파일은 일반 텍스트로 보여 줍니다.

### 링크와 백링크

- 본문에 `[[`를 치면 노트 이름 후보가 뜹니다. 고르면 `[[노트 이름]]`이 들어갑니다.
- 링크를 ⌘클릭하거나 커서를 올리고 ⌘⌥Enter를 누르면 그 노트로 갑니다. 아직 없는 노트는 점선으로 보이고, 따라가면 새로 만들어집니다.
- `[[노트#제목]]`으로 노트 안의 제목에, `[[노트|보이는 이름]]`으로 다른 이름을 붙여 링크합니다.
- 사이드바 **백링크** 칸에는 지금 노트를 링크한 곳(링크된 언급)과, 링크 없이 이름만 적힌 곳(링크 안 된 언급)이 나옵니다.
- **그래프 보기(⌘⌥G)**로 노트들이 어떻게 이어졌는지 한눈에 봅니다. 노드를 누르면 그 노트가 열립니다.

### 태그와 할 일

- `#업무`, `#업무/회의`처럼 태그를 붙이면 사이드바 **태그** 칸에 태그별 노트 수가 나오고, 누르면 그 태그로 검색합니다.
- `- [ ] 할 일`처럼 체크박스를 쓰고 ⌘Enter로 체크합니다. 사이드바 **할 일** 칸에는 모든 노트의 안 한 일이 모이고, 거기서 바로 체크할 수 있습니다.

### 이미지·영상·파일 첨부

- 화면 캡처를 노트에서 ⌘V로 붙여 넣으면, 노트 파일이 있는 폴더 안에 `첨부` 폴더가 생기고 이미지가 저장됩니다. 노트에는 `![](<첨부/Pasted image ….png>)`가 들어갑니다.
- 영상, 오디오, PDF, 오피스 문서는 노트 편집기 위로 끌어다 놓으면 같은 방식으로 첨부됩니다.
- 미리보기에서 이미지는 보이고, 영상과 오디오는 그 자리에서 재생됩니다. 그 밖의 파일은 누르면 기본 앱으로 열립니다.
- 저장하지 않은 새 탭에도 붙여 넣을 수 있습니다. 탭을 저장할 때 첨부도 함께 저장됩니다.
- 링크가 노트 기준 상대 경로라서 노트와 `첨부` 폴더를 함께 옮기면 첨부도 따라갑니다.

### 찾기

- **빠르게 열기(⌘P)**: 노트 이름 몇 글자만 쳐도 찾습니다. ⇧Enter를 누르면 입력한 이름으로 새 노트를 만듭니다.
- **전체 검색(⌘⇧F)**: 공백으로 나눈 조건을 모두 만족하는 줄을 찾습니다. `tag:#업무`, `file:회의`, `path:주제`, `task-todo:`, `-제외어`, `"정확한 문구"`, `/정규식/`을 쓸 수 있습니다.

## 편집과 비교

- **탭 편집**: 파일을 창에 끌어다 놓거나 ⌘O로 엽니다. 저장하지 않은 탭은 이름 앞에 ●이 붙습니다. 파인더의 "다음으로 열기"나 탐색기의 "연결 프로그램"에서 `.md` 파일을 Aurora로 열 수도 있습니다.
- **열 선택과 멀티 커서**: ⌥⇧ 드래그로 열(박스) 선택을, ⌥ 클릭으로 커서 추가를 합니다.
- **번호 넣기(⌘⌥N)**: 커서마다, 또는 선택한 줄마다 번호를 넣습니다. 시작값, 증가값, 0 채우기를 고릅니다.
- **비교**: 다른 탭과(⌘⌥D), 클립보드와(⌘⌥V) 비교합니다. 원본 탭에서 ⌘1을 누르고 다른 탭에서 ⌘⇧C를 누르면 둘을 비교합니다. F7·⇧F7로 차이 사이를 옮겨 다니고, 공백·대소문자 무시를 켤 수 있습니다.
- **JSON·XML 정리(⌘⌥J, ⌘⌥X)**: 선택한 부분이 있으면 그 부분만, 없으면 문서 전체를 정리합니다. 숫자와 중복 키는 바꾸지 않습니다.

## AI 채팅

데스크톱 앱에서만 씁니다. 웹 버전에는 AI 채팅이 없습니다. 브라우저에는 API 키를 안전하게 둘 곳이 없기 때문입니다.

- **열기**: 오른쪽 미리보기 칸 오른쪽 아래의 둥근 반짝이 모양 **AI 채팅** 버튼이나 ⌘J(Notes 메뉴 **AI 채팅 열기/닫기**)로 엽니다.
- **키 넣기**: 채팅 머리의 ⚙ 버튼이나 Notes 메뉴 **AI 설정…**에서 OpenAI, Claude(Anthropic), Gemini(Google) API 키를 붙여 넣고 **저장**을 누릅니다. 모델 목록을 받아 와 키가 맞는지 확인한 뒤에만 저장합니다. 키는 OS 키체인(macOS 키체인, 윈도우 DPAPI)으로 암호화하고 다시 보여 주지 않습니다. 키는 각 회사의 개발자 콘솔(platform.openai.com, console.anthropic.com, aistudio.google.com)에서 만듭니다.
- **고르기**: 채팅 머리에서 회사와 모델을 고릅니다. "기본 모델"은 앱이 알아서 고릅니다. 키가 없는 회사는 "(키 없음)"으로 보입니다.
- **묻기**: Enter로 보내고 ⇧Enter로 줄을 바꿉니다. 답하는 동안에는 버튼이 **중지**로 바뀌고 Esc로도 멈춥니다. 입력 칸 아래 **웹 검색**을 켜면 AI가 직접 웹을 찾아 출처를 보여 주고, **현재 노트 포함**을 켜면 열린 노트와 선택한 글을 함께 보냅니다.
- **답 쓰기**: 답마다 **출처** 링크와 **노트에 넣기**, **복사** 버튼이 붙습니다. **노트에 넣기**는 답과 출처 목록을 커서 자리에 넣거나 선택한 글을 바꾸고, ⌘Z 한 번으로 되돌립니다.
- **그림 만들기**: Gemini의 Nano Banana 모델은 모델 목록에 `(이미지)`가 붙어 보입니다. 이 모델을 고르고 "…그려 줘"처럼 부탁하면 채팅에 그림이 나옵니다. 그림 아래 **노트에 넣기**는 그림을 노트 옆 `첨부` 폴더에 저장하고 `![](<첨부/…>)`를 넣습니다. 저장하지 않은 새 탭이면 탭을 저장할 때 함께 저장합니다. **저장…**은 그림을 다른 곳에 저장합니다. 답의 **노트에 넣기**는 글, 그림, 출처를 함께 넣습니다. 그림은 대화 기록 폴더 안 `첨부` 폴더에도 저장되어 **기록 열기**로 다시 볼 수 있습니다. 앞서 만든 그림을 고쳐 달라는 부탁은 아직 안 되므로 새로 그려 달라고 합니다.
- **출처 표시**: **웹 검색**을 켰는데 답에 출처가 없으면 `검색 출처 없음 · 모델이 웹 검색을 하지 않았을 수 있습니다`가 보입니다. 검색은 했지만 출처를 달지 않았으면 `검색했지만 인용한 출처가 없습니다`가 보입니다. **웹 검색**을 끄면 AI에게 검색했다고 말하지 않도록 알려 줍니다.
- **보기 방식**: AI 설정에서 미리보기와 채팅을 **위아래로 나란히** 둘지, **버튼으로 바꿔 보기**로 할지 고릅니다. 칸 너비와 높이는 경계선을 끌어 맞추고, 앱이 기억합니다.
- **대화 기록**: 대화마다 `2026-10-21 0734 첫 질문.md` 같은 마크다운 파일 하나로 저장합니다. 기본 위치는 노트 폴더의 `.aurora/chats`라 노트와 함께 옮겨 다니고, 노트 목록과 검색에는 나오지 않습니다. **기록 열기**로 지난 대화를 이어 가고 **새 대화**로 새로 시작합니다.

웹 검색은 토큰과 따로 회사마다 요금이 붙습니다. OpenAI와 Claude는 1,000번에 약 10달러, Gemini(Gemini 3 이후)는 한 달 5,000번까지 무료이고 그 뒤로 1,000번에 14달러입니다. 필요 없을 때는 **웹 검색**을 끕니다. 요금은 바뀔 수 있으니 각 회사의 요금 안내를 확인합니다.

그림 만들기는 결제를 연결한 Gemini 키가 있어야 합니다. 무료 키로는 이미지 모델을 쓸 수 없고, 채팅에 `무료 요금제에서는 쓸 수 없는 모델이거나 무료 한도가 없습니다…`라고 나옵니다. 그림 한 장 값은 Nano Banana Pro가 약 0.13달러(1K), Nano Banana 2.1이 약 0.03달러(1K)입니다. 이 값도 바뀔 수 있습니다.

## 클라우드 저장소

데스크톱 앱에서만 씁니다. 노트 폴더를 S3 호환 클라우드 버킷과 맞춰 두면 여러 PC에서 같은 노트를 씁니다. 자세한 설정법은 [사용설명서](docs/사용설명서.md)의 "클라우드 저장소"에 있습니다.

- **서비스**: **Cloudflare R2**를 권합니다. 10GB까지 무료이고 내려받기 요금이 없어 노트 용도로는 사실상 무료입니다. 카드 등록이 필요하지만 무료 범위 안에서는 청구되지 않습니다. 카드 없이 쓰려면 **Backblaze B2**(10GB 무료)를 고릅니다. AWS S3, MinIO 같은 다른 S3 호환 서비스도 됩니다. 가격과 한도는 바뀔 수 있으니 각 서비스의 요금 안내를 확인합니다.
- **켜기**: Notes 메뉴 **저장소 설정…**(또는 상태 표시줄의 ☁ 항목)에서 **클라우드 (S3 호환)**을 고르고 연결 정보를 넣습니다. **연결 확인**으로 확인한 뒤 **클라우드로 바꾸기**를 누릅니다. 먼저 올릴 파일 수와 크기, 내려받을 파일, 충돌 사본, 올라갈 맨 위 폴더를 미리 보여 주고 확인을 받습니다. 500개나 200MB가 넘으면 `노트 폴더가 맞는지 한 번 더 확인하세요.`가 함께 나옵니다. 확인하면 지금 노트 폴더의 노트, 첨부(`첨부` 폴더), AI 대화 기록과 설정(`.aurora`)을 올리고, 그 뒤로 폴더와 버킷을 계속 맞춥니다. 그 밖의 파일(`.git`, zip 파일 등)과 `*.app`, `*.framework`, `*.bundle`, `*.download`, `__MACOSX` 폴더는 올리지 않고, 100MB가 넘는 파일은 건너뜁니다.
- **다른 PC**: 빈 노트 폴더를 고른 뒤 같은 연결 정보를 넣고 **클라우드로 바꾸기**를 누르면 모두 내려받습니다.
- **노트 폴더 바꾸기**: 클라우드를 쓰는 중에 노트 폴더를 바꾸면(메뉴 **노트 폴더 바꾸기…**, 사이드바 아래 경로, 저장소 설정의 버튼) 먼저 묻습니다. 새 폴더를 고르면 클라우드 연결이 끊기고 로컬로 바뀝니다. 폴더 고르기를 취소하면 연결은 그대로입니다. 새 폴더를 맞추려면 저장소 설정에서 다시 **클라우드로 바꾸기**를 누릅니다.
- **맞추는 때**: 저장하면 3초쯤 뒤에 저장한 파일만 올립니다. 클라우드와 전체를 비교하는 때는 앱을 켤 때, 창으로 돌아올 때(30초에 한 번까지), 5분마다, **지금 맞추기**를 누를 때입니다. 앱을 끌 때는 마지막으로 맞춘 뒤 저장한 파일을 올립니다.
- **규칙**: 맞추면서 파일을 지우지는 않습니다. 한 PC에서 지운 파일은 클라우드나 다른 PC에서 다시 돌아오므로 모든 곳에서 지웁니다. 두 PC가 같은 파일을 다르게 고쳤으면 둘 다 남깁니다. 다른 PC의 내용이 원래 이름을 갖고, 이 PC의 내용은 `이름 (충돌 <기기 이름> 10-21 0905).md`로 저장됩니다. 고치지 않은 열린 탭은 저절로 다시 읽고, 고친 탭은 그대로 두었다가 저장할 때 묻습니다. 클라우드에서 받은 내용으로 탭을 바꾸면 그 탭의 되돌리기 기록을 지우므로 ⌘Z로 예전 글이 잘못 돌아오지 않습니다. 내려받은 파일은 크기와(알 수 있으면) MD5를 확인한 뒤에만 기존 파일을 바꿉니다. 새 노트를 만들 때 같은 이름의 파일이 이미 있으면(다른 PC에서 막 받은 경우 등) 덮어쓰지 않고 그 파일을 엽니다.
- **상태 표시줄**: `☁ 맞춤 09:05`, `☁ 맞추는 중 12/40`, `☁ 오프라인`, `☁ 오류`로 보입니다. 오프라인이면 다음 차례에 다시 해 보고, 30초 동안 답이 없는 서버는 오프라인으로 봅니다. 오류는 누르면 자세한 내용이 나옵니다.
- **건너뛴 파일**: 상태 표시줄에 `☁ 맞춤 09:05 · 3개 건너뜀`처럼 보이고, 커서를 올리면 목록이 나옵니다. 저장소 설정에서도 목록을 봅니다. 대소문자만 다른 이름, 100MB가 넘는 파일, 서버에 유니코드 형태만 다른 같은 이름이 둘 있는 파일, 여러 번 다시 해도 맞추지 못한 파일 등이 여기에 들어갑니다.
- **끄기**: **로컬로 바꾸기**를 누르면 맞추기를 멈추고 파일은 그대로 둡니다. 연결 정보를 바꾸려면 로컬로 바꾼 뒤 다시 클라우드로 바꿉니다.
- 비밀 키는 OS 키체인으로 암호화합니다. **연결 확인**은 객체 수와 서비스가 동시 저장 보호를 지원하는지 알려 줍니다. 지원하지 않으면 두 PC에서 동시에 저장할 때 충돌 사본이 생길 수 있습니다.

앱에서 설정하지 않고 맞추려면 노트 폴더를 Google Drive나 OneDrive 폴더 안에 둡니다. 이때는 모든 PC에 그 앱이 깔려 있어야 합니다.

## 단축키

맥 기준 기본값입니다. 앱 메뉴의 **단축키 설정…(⌘,)**에서 모든 메뉴 기능의 단축키를 바꿀 수 있습니다.

- 파일: 새 탭 ⌘N, 열기 ⌘O, 저장 ⌘S, 다른 이름으로 저장 ⌘⇧S, 탭 닫기 ⌘W
- 편집: 찾기 ⌘F, 바꾸기 ⌘⌥F, 번호 넣기 ⌘⌥N, 줄 바꿈 ⌥Z
- 노트: 오늘 노트 ⌘T, 체크박스 ⌘Enter, 사이드바 ⌘B, 미리보기 ⌘⇧V
- 노트 찾기: 빠르게 열기 ⌘P, 전체 검색 ⌘⇧F, 링크 따라가기 ⌘⌥Enter, 그래프 ⌘⌥G
- 비교: 다른 탭과 ⌘⌥D, 클립보드와 ⌘⌥V, 원본 지정 ⌘1, 원본과 비교 ⌘⇧C, 다음·이전 차이 F7·⇧F7, 닫기 Esc
- 정리: JSON ⌘⌥J, XML ⌘⌥X
- AI: 채팅 열기·닫기 ⌘J

자세한 설명은 [사용설명서](docs/사용설명서.md)에 있습니다.

## 알아둘 점

- 노트 폴더 아래 모든 `.md` 파일과, txt·html 같은 텍스트 파일(1MB 이하)을 읽어 색인합니다. `.`으로 시작하는 폴더(`.obsidian`, `.git`)와 `node_modules`는 건너뜁니다. 파일이 아주 많은 폴더(다운로드 폴더 등)를 노트 폴더로 잡으면 느려질 수 있습니다.
- 노트 폴더는 사이드바 아래 경로를 누르거나 Notes 메뉴의 **노트 폴더 바꾸기…**로 바꿉니다.
- 맥과 윈도우에서 함께 쓸 수 있도록 노트·폴더 이름에 `< > : " | ? *`는 쓰지 못하게 막습니다.
- 파일을 연 뒤 Aurora 밖(다른 앱, 또는 클라우드로 맞춘 다른 기기)에서 바뀌었으면, 저장할 때 **덮어쓰기**와 **취소** 중 고르라고 묻습니다. **취소**를 누르면 다른 이름으로 저장하거나 비교해 볼 수 있습니다.
- 파일은 UTF-8로 읽고 씁니다. 화면 색은 시스템의 다크·라이트 모드를 따릅니다.
- 웹 버전은 크롬·엣지의 폴더 접근 기능으로 노트 폴더를 직접 읽고 씁니다. 다른 브라우저에서는 파일을 하나씩 열고 내려받기로 저장합니다.
- 미리보기와 AI 채팅은 HTML에서 스크립트와 폼을 걷어 내고 보여 줍니다. AI 답을 노트에 넣어도 코드가 실행되지 않습니다.
- 예전 이름은 Quire, 그 전에는 TextBench입니다. 처음 실행할 때 예전 앱의 노트 폴더 설정과 단축키를 옮겨 옵니다.

## 개발

Node 20.19 이상이 필요합니다.

1. `npm install`로 의존성을 설치합니다. electron 바이너리가 받아지지 않았으면 `node node_modules/electron/install.js`를 한 번 실행합니다.
2. `npm run dev`로 개발 모드를 띄우고, `npm test`로 단위 테스트를 돌립니다.
3. `npm run build`로 타입 검사와 빌드를 합니다.
4. `npm run dist`로 맥 앱과 설치 파일(pkg)을, `npm run dist:win`으로 윈도우 설치 파일(exe)을 `release/`에 만듭니다. 윈도우 빌드는 맥에서도 만들 수 있습니다.
5. `npm run dev:web`으로 웹 버전을 띄우고, `npm run build:web`으로 `dist/`에 올릴 파일을 만듭니다.
6. 아이콘은 `build/icon.svg`를 고친 뒤 `scripts/icons.sh`로 맥·윈도우·웹 아이콘을 다시 만듭니다.
7. 키체인에 "Developer ID Application" 인증서가 있으면 `npm run dist`가 맥 앱에 서명합니다. 프로젝트 맨 위의 `electron-builder.env`에 `APPLE_API_KEY`(.p8 파일 경로), `APPLE_API_KEY_ID`, `APPLE_API_ISSUER`를 적어 두면 공증까지 합니다. 인증서가 없으면 서명하지 않고 만듭니다. `electron-builder.env`는 git에 올리지 않습니다.

구조는 다음과 같습니다.

- `electron/`: 메인 프로세스(창, 메뉴, 파일 입출력), preload, 명령·단축키 정의
- `electron/ai/`: OpenAI·Claude·Gemini 호출과 대화 기록 저장 형식(키 보관은 `electron/secrets.ts`, 연결은 `electron/aiHost.ts`)
- `electron/cloud/`: S3 호환 클라우드 저장소와 노트 폴더 맞추기
- `src/main.ts`: 화면 진입점(탭, 비교, 노트, 명령 처리)
- `src/lib/`: 테스트할 수 있는 순수 로직(데일리 노트, 링크·검색·그래프, 첨부, 번호, JSON·XML 정리)
- `src/ui/`: 대화상자, 빠른 열기, 그래프 화면
- `src/web/`: 웹 버전의 파일 입출력
- `tests/`: vitest 단위 테스트
