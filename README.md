# Aurora

Notepad++와 Beyond Compare를 대신해 쓰려고 만든 개인용 맥 텍스트 편집·비교 도구입니다. VS Code와 같은 편집 엔진(Monaco)을 Electron으로 감쌌습니다.

## 기능

- **탭 편집.** 새 탭, 파일 열기·저장·다른 이름으로 저장, 창에 파일을 끌어다 놓아 열기를 지원합니다. 저장하지 않은 탭은 탭 이름 앞에 ● 표시가 붙고, 닫거나 종료할 때 확인을 받습니다.
- **열 선택과 멀티 커서.** ⌥⇧ 드래그로 열(박스) 선택을 하고, ⌥ 클릭으로 커서를 더합니다.
- **선택한 줄마다 번호 넣기.** 커서가 여럿이면 커서마다, 여러 줄을 선택했으면 그 줄마다 선택 시작 열에 번호를 넣습니다. 시작값, 증가값, 자릿수 맞춰 0 채우기를 고를 수 있습니다.
- **비교.** 현재 탭과 다른 탭, 현재 탭과 클립보드, 디스크의 두 파일을 비교합니다. 다음·이전 차이로 이동할 수 있고, 공백 무시와 대소문자 무시를 켜고 끌 수 있습니다. 탭끼리 비교할 때는 오른쪽에서 고친 내용이 탭에 바로 반영됩니다.
- **비교 원본 지정.** 원본으로 삼을 탭에서 ⌘1을 누르고, 다른 탭으로 옮긴 뒤 ⌘⇧C를 누르면 원본(왼쪽)과 현재 탭(오른쪽)을 비교합니다.
- **업무 노트(데일리 노트).** ⌘T를 누르면 오늘 노트를 엽니다. 처음 한 번 노트 폴더를 고르면 `daily/YYYY-MM-DD.md` 파일로 쌓입니다. 노트는 스탠드업 형식(어제 한 일, 오늘 할 일, 이슈, 메모)이고, 새 노트를 만들 때 가장 최근 노트의 "오늘 할 일"에서 체크한 일은 "어제 한 일"로, 체크 안 한 일은 하위 항목과 함께 "오늘 할 일"로 넘겨받습니다. 지난 노트는 고치지 않습니다. 평범한 마크다운이라 Obsidian으로도 열 수 있습니다.
- **노트 사이드바와 미리보기.** 달력 사이드바는 처음부터 켜져 있고 탭 막대의 사이드바 버튼이나 ⌘B로 숨기며, 날짜를 누르면 그날 노트를 열거나 만듭니다. 마크다운 미리보기도 처음부터 켜져 있고 ⌘⇧V로 끄고 켭니다. ⌘Enter로 커서가 있는 줄의 체크박스를 토글합니다.
- **[[링크]]와 백링크.** 노트에 `[[노트 이름]]`을 쓰면 다른 노트로 이어집니다. `[[`를 치면 노트 이름을 제안하고, ⌘클릭이나 ⌘⌥Enter로 링크를 따라갑니다. 없는 노트로 가는 링크는 점선으로 보이고, 따라가면 새 노트를 만듭니다. `[[노트#제목|별칭]]` 형식도 읽습니다. 사이드바의 백링크 칸은 지금 노트를 가리키는 링크와, 링크 없이 이름만 적힌 곳을 따로 보여 줍니다. 링크 해석 규칙(같은 이름이 여럿이면 가까운 폴더, 그다음 짧은 경로)은 옵시디언과 같습니다.
- **노트 빠르게 열기(⌘P)와 전체 검색(⌘⇧F).** 빠른 열기는 퍼지 검색이라 글자 몇 개만 쳐도 찾고, ⇧Enter로 입력한 이름의 노트를 만듭니다. 전체 검색은 공백으로 나눈 조건을 모두 만족하는 줄을 찾습니다. `file:`, `path:`, `tag:`, `task:`, `task-todo:`, `task-done:`, `line:` 연산자와 `-제외`, `"정확한 문구"`, `/정규식/`을 쓸 수 있습니다.
- **이미지·영상·파일 첨부.** 클립보드 이미지를 ⌘V로 붙여 넣거나 파일을 노트에 끌어다 놓으면 노트 옆 `첨부` 폴더에 저장하고 상대 경로 링크를 넣습니다. 미리보기에서 이미지는 보이고 영상·오디오는 재생됩니다.
- **노트 목록.** 사이드바의 노트 칸은 데일리 노트를 뺀 노트를 폴더별로 보여 주고, 노트마다 그 노트를 링크한 노트 수를 붙입니다. + 날짜, + 주제, + 목차 버튼으로 오늘 노트를 열거나 주제·목차 노트를 틀과 함께 만듭니다. 종류별 저장 폴더는 Notes 메뉴의 "노트 저장 위치…"에서 전체 경로로 정합니다.
- **태그와 할 일 모아보기.** 사이드바의 태그 칸은 `#태그`(중첩 태그 `#업무/회의` 포함)별 노트 수를 보여 주고, 누르면 그 태그로 검색합니다. 할 일 칸은 모든 노트의 안 한 체크박스를 모으고, 체크하면 그 노트에 바로 반영합니다.
- **그래프 보기(⌘⌥G).** 노트와 링크를 그래프로 그립니다. 끌기, 휠 확대, 마우스를 올리면 이웃 강조, 누르면 노트 열기를 지원하고, 현재 노트 주변(2단계)만 보거나 태그를 노드로 넣을 수 있습니다.
- **JSON·XML 정리와 압축.** 선택한 부분이 있으면 그 부분만, 없으면 문서 전체를 바꿉니다.
- **보기 설정.** 줄 바꿈, 공백 문자 표시를 켜고 끕니다. 화면 색은 시스템의 다크·라이트 모드를 따릅니다.

자세한 사용 방법은 [사용설명서](docs/사용설명서.md)에 있습니다.

## 단축키

아래는 맥 기준 기본값입니다. 윈도우에서는 ⌘ 대신 Ctrl, ⌥ 대신 Alt를 누르고, 화면에도 Ctrl+Shift+F처럼 표시됩니다. [[링크]]는 ⌘클릭 대신 Ctrl+클릭으로 따라갑니다. 윈도우에는 메뉴 막대가 없으므로 탭 막대 맨 왼쪽의 ☰ 버튼으로 메뉴를 엽니다.

아래는 기본값입니다. 앱 메뉴의 **단축키 설정…(⌘,)**에서 메뉴의 모든 기능의 단축키를 바꾸거나 지울 수 있습니다. 키 칸을 누르고 원하는 조합을 누르면 되고, 다른 기능이 쓰던 키를 고르면 그 기능에서 떼어 옵니다. 글자 키는 ⌘, ⌃, ⌥ 중 하나와 함께 눌러야 하고, 잘라내기·복사·붙여넣기·종료처럼 시스템이 쓰는 키는 고를 수 없습니다. 설정은 앱 설정 폴더의 `config.json`에 저장됩니다.

- 새 탭 ⌘N, 열기 ⌘O, 저장 ⌘S, 다른 이름으로 저장 ⌘⇧S, 탭 닫기 ⌘W
- 찾기 ⌘F, 바꾸기 ⌘⌥F
- 번호 넣기 ⌘⌥N
- 다른 탭과 비교 ⌘⌥D, 클립보드와 비교 ⌘⌥V
- 비교 원본 지정 ⌘1, 원본과 현재 탭 비교 ⌘⇧C
- 오늘 노트 ⌘T, 체크박스 토글 ⌘Enter, 노트 사이드바 ⌘B, 마크다운 미리보기 ⌘⇧V
- 노트 빠르게 열기 ⌘P, 노트 전체 검색 ⌘⇧F, 링크 따라가기 ⌘⌥Enter, 그래프 보기 ⌘⌥G (Esc로 닫기)
- 다음 차이 F7, 이전 차이 ⇧F7, 비교 닫기 Esc (편집기에서 찾기 창이 열려 있으면 Esc가 찾기 창부터 닫습니다. Esc는 바꿀 수 없습니다)
- JSON 정리 ⌘⌥J, XML 정리 ⌘⌥X
- 줄 바꿈 ⌥Z
- 단축키 설정 ⌘,

## 알아둘 점

- 대소문자 무시는 양쪽을 소문자로 바꾼 사본끼리 비교합니다. 그래서 이 옵션을 켠 동안에는 화면에 소문자로 보이고 편집할 수 없습니다.
- 파일은 UTF-8로 읽고 씁니다.
- 예전 이름은 Aurora, 그 전에는 TextBench입니다. 처음 실행할 때 `Aurora`(없으면 `TextBench`) 설정 폴더의 `config.json`(노트 폴더, 단축키)을 `Aurora` 설정 폴더로 옮겨 옵니다.
- 노트 폴더 아래 모든 `.md` 파일을 읽어 색인합니다. `.`으로 시작하는 폴더(`.obsidian`, `.git`)와 `node_modules`는 건너뜁니다. 노트 폴더를 파일이 아주 많은 곳(다운로드 폴더 등)으로 잡으면 느려질 수 있습니다.
- 화면은 맥(반투명 사이드바, 신호등 버튼 자리의 탭 막대), 윈도우(오른쪽 창 버튼 자리를 비운 탭 막대), 웹(일반 탭 막대)으로 나눠 그립니다.
- 웹 버전은 크롬·엣지의 폴더 접근 기능(File System Access API)으로 노트 폴더를 직접 읽고 씁니다. 다른 브라우저에서는 파일을 하나씩 열고 내려받기로 저장합니다. 브라우저가 먼저 가로채는 키(⌘T, ⌘N, ⌘W)는 단축키 설정에서 바꿔 씁니다.
- 노트 폴더는 사이드바 아래 경로를 누르거나 Notes → 노트 폴더 바꾸기로 바꿉니다.

## 실행과 빌드

Node 20.19 이상이 필요합니다.

1. `npm install`로 의존성을 설치합니다. electron 바이너리가 받아지지 않았으면 `node node_modules/electron/install.js`를 한 번 실행합니다.
2. `npm run dev`로 개발 모드를 띄웁니다.
3. `npm test`로 단위 테스트를 돌립니다.
4. `npm run build`로 타입 검사와 빌드를 합니다.
5. `npm run dist`로 `release/` 폴더에 맥 앱(.app)과 설치 파일(.dmg)을 만듭니다. 서명하지 않은 앱이므로 처음 열 때 Finder에서 우클릭 후 열기를 선택합니다.
6. `npm run dist:win`으로 `release/` 폴더에 윈도우 설치 파일(`Aurora Setup 0.1.0.exe`, x64·ARM 겸용)과 압축 파일(`Aurora-0.1.0-win.zip`, `Aurora-0.1.0-arm64-win.zip`)을 만듭니다. 맥에서도 만들 수 있습니다. 서명하지 않았으므로 처음 실행할 때 SmartScreen 경고가 뜨면 "추가 정보 → 실행"을 누릅니다.
7. `npm run dev:web`으로 웹 버전을 브라우저에서 띄우고, `npm run build:web`으로 `dist/`에 올릴 파일을 만듭니다.

## 구조

- `electron/` 메인 프로세스(창, 메뉴, 파일 입출력)와 preload, 메인·렌더러가 함께 쓰는 명령·단축키 정의(`keybindings.ts`)
- `src/main.ts` 렌더러 진입점(탭, 비교, 명령 처리)
- `src/lib/` 테스트 가능한 순수 로직(번호 생성, JSON·XML 정리, 비교 전처리, 언어 판별, 데일리 노트)
- `src/ui/` 모달 대화상자
- `tests/` vitest 단위 테스트
