# Aurora 사용설명서

Aurora는 텍스트 편집, 두 파일 비교, 마크다운 업무 노트를 한 곳에서 하는 앱입니다. 맥, 윈도우, 웹 브라우저에서 씁니다. 노트는 평범한 `.md` 파일이라 옵시디언으로도 열 수 있습니다.

이 문서의 단축키는 맥 기준입니다. 윈도우와 리눅스에서는 ⌘ 대신 Ctrl, ⌥ 대신 Alt를 누릅니다.

## 1. 설치와 실행

### 맥

1. `/Applications/Aurora.app`을 엽니다. Launchpad나 Spotlight에서 "Aurora"로 찾아도 됩니다.
2. 새로 빌드하려면 프로젝트 폴더에서 `npm run dist`를 실행합니다. `release/` 폴더에 `.app`과 설치 파일 `.pkg`가 생깁니다.
3. 다른 맥에는 `.pkg`로 설치합니다. 서명하지 않은 설치 파일이라 처음 열 때 막히면 시스템 설정 > 개인정보 보호 및 보안에서 "그래도 열기"를 누릅니다(macOS 14 이하는 설치 파일을 우클릭한 뒤 "열기"). 설치 프로그램이 앱의 격리 표시를 지우므로 설치한 앱은 경고 없이 열립니다.

### 윈도우

1. 맥에서 `npm run dist:win`을 실행하면 `release/` 폴더에 설치 파일 `Aurora Setup 0.1.0.exe`가 생깁니다.
2. 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 "추가 정보"를 누른 뒤 "실행"을 누릅니다.
3. 윈도우에는 메뉴 막대가 없습니다. 탭 막대 맨 왼쪽의 ☰ 버튼으로 메뉴를 엽니다.

### 웹

1. 프로젝트 폴더에서 `npm run dev:web`을 실행하고 터미널에 나온 주소를 브라우저로 엽니다.
2. 서버에 올리려면 `npm run build:web`으로 만든 `dist/` 폴더를 그대로 올리면 됩니다.
3. 노트 폴더 기능은 크롬과 엣지에서만 됩니다. 사파리와 파이어폭스에서는 파일을 하나씩 열고, 저장하면 내려받기로 저장됩니다.
4. 메뉴는 탭 막대 맨 왼쪽의 ☰ 버튼입니다.

## 2. 노트 폴더 정하기

- 노트 기능을 처음 쓸 때 노트를 모아 둘 폴더를 고릅니다. 나중에 바꾸려면 메뉴의 **Notes → 노트 폴더 바꾸기…**를 누르거나 사이드바 맨 아래 경로를 누릅니다.
- 옵시디언 vault 폴더를 골라도 됩니다. 같은 파일을 함께 씁니다.
- 노트 폴더 아래 모든 `.md` 파일과, txt·html 같은 텍스트 파일(1MB 이하)을 읽습니다. `.`으로 시작하는 폴더(`.obsidian`, `.git`)와 `node_modules`는 건너뜁니다. 다운로드 폴더처럼 파일이 아주 많은 곳은 느려질 수 있으니 노트 전용 폴더를 권합니다.
- 웹에서는 브라우저가 폴더 접근 권한을 묻습니다. "파일 수정 허용"을 눌러야 저장할 수 있습니다. 다음에 열 때 권한을 한 번 더 물을 수 있습니다.

## 3. 매일 쓰는 흐름 (데일리 노트)

1. **⌘T**로 오늘 노트를 엽니다. 노트 폴더의 `daily/YYYY-MM-DD.md`로 저장됩니다.
2. 새 노트를 만들 때 가장 최근 노트의 "오늘 할 일"에서 체크한 일은 "어제 한 일"로, 체크하지 않은 일은 하위 항목과 함께 "오늘 할 일"로 넘어옵니다. 지난 노트는 고치지 않습니다.
3. 사이드바는 처음부터 켜져 있습니다. 탭 막대 왼쪽의 사이드바 버튼이나 **⌘B**로 숨기고 다시 켭니다. 달력에서 날짜를 누르면 그날 노트를 열거나 만듭니다. 점이 찍힌 날은 노트가 있는 날입니다.
4. 할 일 줄에서 **⌘Enter**를 누르면 체크박스가 토글됩니다.
5. 오른쪽 마크다운 미리보기도 처음부터 켜져 있습니다. **⌘⇧V**로 끄고 켭니다.

### 이미지·영상·파일 첨부

- 화면 캡처처럼 클립보드에 있는 이미지를 노트에서 **⌘V**(윈도우는 Ctrl+V)로 붙여 넣으면, 노트 파일이 있는 폴더 안에 `첨부` 폴더를 만들어 `Pasted image 20261020081530.png` 같은 이름으로 저장하고 커서 자리에 `![](<첨부/Pasted image ….png>)`를 넣습니다.
- 파인더·탐색기에서 이미지, 영상, 오디오, PDF, 오피스 문서를 노트 편집기 위로 끌어다 놓아도 같은 `첨부` 폴더에 복사하고 링크를 넣습니다. 같은 이름이 있으면 번호를 붙입니다.
- 미리보기에서 이미지는 바로 보이고, 영상과 오디오는 그 자리에서 재생됩니다. 그 밖의 파일은 누르면 기본 앱으로 열립니다.
- 링크가 노트 기준 상대 경로라서 노트와 `첨부` 폴더를 함께 옮기면 첨부도 따라갑니다. 옵시디언, 타이포라, 깃허브에서도 그대로 보입니다.
- 엑셀이나 웹 페이지처럼 글과 그림을 함께 복사한 경우는 글을 붙여 넣습니다.
- 저장하지 않은 새 탭에도 붙여 넣을 수 있습니다. 첨부는 탭이 들고 있다가(미리보기에는 바로 보입니다) 탭을 저장할 때 노트 옆 `첨부` 폴더에 함께 저장됩니다. 그 사이 링크를 지운 첨부는 저장하지 않고, 같은 이름 파일이 이미 있으면 번호를 붙이고 링크도 그 이름으로 고칩니다.

## 4. 노트끼리 연결하기

- 본문에 `[[`를 치면 노트 이름 목록이 뜹니다. 고르면 `[[프로젝트 A]]`처럼 들어갑니다.
- 링크를 따라가려면 링크 위에서 **⌘클릭**(윈도우는 Ctrl+클릭)하거나, 커서를 링크에 두고 **⌘⌥Enter**를 누릅니다. 미리보기에서는 링크를 그냥 누르면 됩니다.
- 아직 없는 노트 이름은 점선 밑줄로 보입니다. 따라가면 그 이름으로 새 노트가 노트 폴더 맨 위에 만들어집니다.
- `[[노트#제목]]`은 그 제목 위치로 갑니다. `[[노트|보일 이름]]`은 다른 이름으로 표시합니다.
- 같은 이름의 노트가 여러 폴더에 있으면 지금 노트와 가까운 폴더의 노트, 그다음 경로가 짧은 노트로 갑니다. 정확히 가리키려면 `[[work/회의록]]`처럼 폴더를 붙입니다.
- 본문에 `#업무`, `#업무/회의`처럼 쓰면 태그가 됩니다. 공백 뒤나 줄 맨 앞에 있어야 하고, 숫자로만 된 `#123`은 태그가 아닙니다.

## 5. 사이드바의 네 칸

- **노트**는 데일리 노트를 뺀 노트를 폴더별로 보여 줍니다. 오른쪽 숫자는 그 노트를 링크한 노트 수라서, 목차 노트나 자주 언급되는 주제 노트가 눈에 띕니다. 맨 위 버튼 세 개로 노트를 만듭니다. **+ 날짜**는 오늘 데일리 노트를 열고, **+ 주제**와 **+ 목차**는 이름을 물어 `주제/`, `목차/` 폴더에 틀(`#주제`·`#목차` 태그와 기본 제목)을 넣은 노트를 만듭니다. Notes 메뉴의 "노트 저장 위치…"에서 날짜·주제·목차 노트를 둘 폴더를 전체 경로로 정합니다. **찾아보기…**로 폴더를 고르거나 경로를 직접 적습니다. 폴더는 노트 폴더 안에 있어야 링크와 검색에 잡히므로, 바깥 폴더를 쓰려면 노트 폴더부터 바꿉니다(웹은 경로를 직접 적습니다). 기본값은 `daily`, `주제`, `목차`이고, 설정은 노트 폴더의 `.aurora/folders.json`에 저장됩니다. 폴더를 바꿔도 이미 있는 노트는 옮기지 않습니다. `공부/Electron`처럼 폴더를 적으면 그 폴더에 만들고, 이미 있는 노트면 그 노트를 엽니다.
- **백링크**는 지금 노트를 `[[ ]]`로 가리키는 곳(링크된 언급)과, 링크 없이 노트 이름만 적힌 곳(링크 안 된 언급)을 보여 줍니다. 항목을 누르면 그 줄로 갑니다.
- **태그**는 태그별 노트 수를 보여 줍니다. 중첩 태그는 들여 써서 보이고, 누르면 그 태그로 전체 검색을 합니다.
- **할 일**은 모든 노트의 안 한 체크박스를 노트별로 모아 보여 줍니다. 체크하면 그 노트 파일에 바로 반영됩니다. 그 노트가 탭으로 열려 있으면 탭 내용만 바뀌므로 저장해야 합니다.

### 새 파일 형식

- **노트** 칸 맨 위 **+ 날짜**, **+ 주제**, **+ 목차** 옆의 **+ 파일**로 마크다운이 아닌 파일도 만듭니다. 이름을 넣고 **형식**에서 마크다운(.md), 텍스트(.txt), 웹 페이지(.html), CSS, 자바스크립트, JSON, CSV, XML, YAML, SQL, 셸 스크립트, 파이썬 중 하나를 고릅니다. 이름에 확장자를 치면 형식이 저절로 골라집니다.
- **+ 주제**와 **+ 목차**에서도 형식을 고를 수 있습니다. 마크다운이 아닌 파일은 빈 내용으로, html은 기본 페이지 뼈대로 시작합니다. 날짜 노트는 그대로 `.md`입니다.
- 노트 폴더 안의 텍스트 파일(위 확장자와 htm, ts, yml, log, markdown)은 노트 목록, 빠르게 열기, 전체 검색에 나옵니다. `.md`가 아닌 파일은 1MB까지만 읽습니다. `[[링크]]`, 백링크, 태그, 할 일, 그래프는 마크다운 파일에만 해당합니다.
- 미리보기는 마크다운을 전처럼 보여 주고, html은 웹 페이지로 보여 줍니다. 이때 스크립트, 폼, style 태그는 걷어 냅니다. 그 밖의 파일은 일반 텍스트로 보여 줍니다.

## 6. 찾기

### 빠르게 열기 (⌘P)

- 노트 이름이나 경로 일부만 쳐도 찾습니다. 글자가 띄엄띄엄 맞아도 됩니다.
- 검색어가 비어 있으면 열린 탭과 최근에 고친 노트가 먼저 나옵니다.
- **Enter**는 고른 노트를 열고, **⇧Enter**는 입력한 이름으로 새 노트를 만듭니다. 이름에 `.txt`, `.html` 같은 확장자를 붙이면 그 형식의 파일을 만듭니다.

### 전체 검색 (⌘⇧F)

공백으로 나눈 조건을 모두 만족하는 노트와 줄을 찾습니다. 아래 형식을 섞어 쓸 수 있습니다.

```
배포 확인          두 단어가 모두 있는 노트
"배포 확인"        정확히 이 문구
배포 -리뷰         배포는 있고 리뷰는 없는 노트
tag:#업무          #업무 태그 (하위 태그 #업무/리뷰 포함)
path:daily         경로에 daily가 들어간 노트
file:회의          파일 이름에 회의가 들어간 노트
task:배포          배포가 들어간 할 일 (한 일, 안 한 일 모두)
task-todo:배포     안 한 할 일 중 배포가 들어간 것
task-done:리뷰     끝낸 할 일 중 리뷰가 들어간 것
/\d단계/           정규식
```

## 7. 그래프 (⌘⌥G)

- 노트를 점으로, 링크를 선으로 그립니다. 연결이 많은 노트일수록 점이 큽니다. 없는 노트로 가는 링크는 흐린 점으로 보입니다.
- 점을 끌어 옮기고, 휠로 확대·축소하고, 빈 곳을 끌어 화면을 옮깁니다.
- 점에 마우스를 올리면 연결된 노트만 강조되고, 누르면 그 노트가 열립니다.
- "현재 노트 주변만"을 켜면 그래프를 열 때의 노트에서 2단계까지만 보입니다. "태그 보기"를 켜면 태그도 초록 점으로 그립니다.
- **Esc**나 **⌘⌥G**로 닫습니다.

## 8. 편집 도구

- **탭.** ⌘N 새 탭, ⌘O 열기, ⌘S 저장, ⌘⇧S 다른 이름으로 저장, ⌘W 탭 닫기입니다. 창에 파일을 끌어다 놓아도 열립니다. 저장하지 않은 탭은 이름 앞에 ● 표시가 붙습니다.
- **열 선택과 멀티 커서.** ⌥⇧ 드래그로 박스 모양 선택을, ⌥클릭으로 커서를 더합니다.
- **번호 넣기 (⌘⌥N).** 커서마다, 또는 여러 줄을 선택했으면 줄마다 번호를 넣습니다. 시작값, 증가값, 0 채우기를 고릅니다.
- **JSON·XML 정리 (⌘⌥J, ⌘⌥X).** 선택한 부분이 있으면 그 부분만, 없으면 문서 전체를 정리합니다. 압축은 메뉴의 Tools에 있습니다.
- **보기.** ⌥Z 줄 바꿈, 메뉴의 View에서 공백 문자 표시를 켜고 끕니다.

## 9. 비교

- **⌘⌥D**는 현재 탭과 다른 탭을, **⌘⌥V**는 현재 탭과 클립보드를 비교합니다. 디스크의 두 파일 비교는 메뉴의 Compare에 있습니다.
- 원본으로 삼을 탭에서 **⌘1**을 누르고 다른 탭으로 옮긴 뒤 **⌘⇧C**를 누르면 원본(왼쪽)과 현재 탭(오른쪽)을 비교합니다.
- **F7**과 **⇧F7**로 다음·이전 차이로 이동하고, **Esc**로 닫습니다.
- 위쪽 막대에서 공백 무시와 대소문자 무시를 켜고 끕니다. 대소문자 무시를 켠 동안에는 소문자 사본끼리 비교하므로 편집할 수 없습니다.

## 10. 단축키 바꾸기

1. **⌘,**로 단축키 설정을 엽니다. 윈도우와 웹에서는 ☰ 메뉴에도 있습니다.
2. 바꿀 기능의 키 칸을 누르고 원하는 조합을 누릅니다. 다른 기능이 쓰던 키면 그 기능에서 떼어 옵니다.
3. 글자 키는 ⌘, ⌃, ⌥(윈도우는 Ctrl, Alt) 중 하나와 함께 눌러야 합니다.
4. 데스크톱 앱은 설정 폴더의 `config.json`에, 웹은 브라우저에 저장됩니다.

웹에서는 브라우저가 먼저 가로채는 키가 있습니다. 크롬의 ⌘T(새 탭), ⌘N(새 창), ⌘W(탭 닫기)는 Aurora까지 오지 않으므로 단축키 설정에서 다른 키로 바꿔 쓰거나 ☰ 메뉴를 씁니다.

## 11. AI 채팅

AI 채팅은 데스크톱 앱에서만 씁니다. 웹 버전에는 없습니다. 브라우저에는 API 키를 안전하게 둘 곳이 없기 때문입니다.

- 오른쪽 미리보기 칸 오른쪽 아래의 둥근 반짝이 모양 **AI 채팅** 버튼을 누르거나 **⌘J**(Notes 메뉴 **AI 채팅 열기/닫기**)를 누르면 채팅이 열립니다.
- 설정은 채팅 머리의 ⚙ 버튼이나 Notes 메뉴 **AI 설정…**으로 엽니다. **AI 설정**은 회사, 보기 방식, 대화 기록 폴더, 기본값 칸으로 나뉩니다.

### 키 넣기

1. 쓸 회사의 개발자 콘솔에서 API 키를 만듭니다. OpenAI는 platform.openai.com, Claude(Anthropic)는 console.anthropic.com, Gemini(Google)는 aistudio.google.com입니다.
2. **AI 설정**의 회사 칸에 키를 붙여 넣고 **저장**을 누릅니다. 앱이 먼저 모델 목록을 받아 와 키가 맞는지 확인하고, 맞을 때만 저장합니다.
3. 키는 OS 키체인(macOS 키체인, 윈도우 DPAPI)으로 암호화해 두고 다시 보여 주지 않습니다. 지우려면 **삭제**를 누릅니다.

채팅 머리에서 회사와 모델을 고릅니다. "기본 모델"을 고르면 앱이 알아서 정합니다. 키가 없는 회사는 "(키 없음)"으로 보입니다.

### 묻고 답 받기

- **Enter**로 보내고 **⇧Enter**로 줄을 바꿉니다. 답하는 동안 **보내기** 버튼이 **중지**로 바뀝니다. **Esc**로도 멈출 수 있습니다.
- 입력 칸 아래에 켜고 끄는 단추가 두 개 있습니다. **웹 검색**을 켜면 AI가 직접 웹을 찾아보고 출처를 보여 줍니다. **현재 노트 포함**을 켜면 열린 노트와, 선택한 글이 있으면 그 글을 함께 보냅니다. 두 단추의 처음 상태는 **AI 설정**의 기본값 칸에서 정합니다.
- **웹 검색**을 켰는데 답에 출처가 없으면 답 아래에 `검색 출처 없음 · 모델이 웹 검색을 하지 않았을 수 있습니다`가 보입니다. 검색은 했지만 출처를 달지 않았으면 `검색했지만 인용한 출처가 없습니다`가 보입니다. **웹 검색**을 끄면 AI에게 검색했다고 말하지 않도록 알려 줍니다.
- 키가 틀렸을 때, 사용량이나 크레딧이 모자랄 때, 요청이 너무 많을 때, 네트워크가 끊겼을 때는 채팅에 한국어로 알려 줍니다. 오류가 나면 질문이 입력 칸으로 돌아오므로 다시 보내면 됩니다.

웹 검색은 토큰과 따로 회사마다 요금이 붙습니다. OpenAI와 Claude는 1,000번에 약 10달러입니다. Gemini(Gemini 3 이후)는 한 달 5,000번까지 무료이고, 그 뒤로 1,000번에 14달러입니다. 필요 없을 때는 **웹 검색**을 끄는 편이 좋습니다. 요금은 바뀔 수 있으니 각 회사의 요금 안내를 확인합니다.

### 노트에 넣기

- 답마다 **출처** 링크가 붙습니다. 누르면 기본 브라우저로 열립니다.
- **노트에 넣기**는 답과 `**출처**` 링크 목록을 커서 자리에 넣습니다. 선택한 글이 있으면 그 글을 바꿉니다. **⌘Z** 한 번으로 통째로 되돌립니다.
- **복사**는 같은 마크다운을 클립보드에 복사합니다.
- Gemini 답에는 Google 검색 추천 단추가 함께 보일 수 있습니다. Google이 꼭 보여 주도록 정한 것입니다.
- 미리보기와 채팅은 HTML에서 스크립트와 폼을 걷어 내고 보여 줍니다. 그래서 노트에 넣은 답이 코드를 실행할 수 없습니다.

### 그림 만들기

1. Gemini의 Nano Banana 모델은 모델 목록에 `(이미지)`가 붙어 보입니다. 이 모델을 고릅니다.
2. "고양이가 노트북을 보는 그림 그려 줘"처럼 부탁하면 채팅에 그림이 나옵니다.
3. 그림 아래 **노트에 넣기**를 누르면 그림을 노트 옆 `첨부` 폴더에 저장하고 커서 자리에 `![](<첨부/…>)`를 넣습니다. 저장하지 않은 새 탭이면 탭을 저장할 때 함께 저장합니다. **저장…**은 그림을 다른 곳에 저장합니다.
4. 답의 **노트에 넣기**는 글, 그림, 출처를 함께 넣습니다.

- 그림은 대화 기록과 함께 저장됩니다. 대화 기록 폴더 안 `첨부` 폴더에 들어가고, **기록 열기**로 그 대화를 열면 다시 보입니다.
- 앞서 만든 그림을 이어서 고쳐 달라는 부탁은 아직 안 됩니다. 새 그림을 그려 달라고 합니다.
- 결제를 연결한 Gemini 키가 있어야 합니다. 무료 키로는 이미지 모델을 쓸 수 없고, 채팅에 `무료 요금제에서는 쓸 수 없는 모델이거나 무료 한도가 없습니다…`라고 나옵니다.
- 그림 한 장 값은 Nano Banana Pro가 약 0.13달러(1K), Nano Banana 2.1이 약 0.03달러(1K)입니다. 요금은 바뀔 수 있습니다.

### 보기 방식

**AI 설정**의 보기 방식에서 고릅니다.

- **위아래로 나란히**는 위에 미리보기, 아래에 채팅을 둡니다. 둘 사이의 선을 끌어 높이를 맞춥니다.
- **버튼으로 바꿔 보기**는 AI 버튼을 누를 때마다 미리보기와 채팅을 바꿔 보여 줍니다.
- 칸의 왼쪽 가장자리를 끌면 너비를 바꿉니다. 크기와 보기 방식은 앱이 기억합니다.

### 대화 기록

- 대화마다 `2026-10-21 0734 첫 질문.md` 같은 이름의 마크다운 파일 하나로 저장합니다.
- 기본 위치는 노트 폴더 안의 `.aurora/chats`입니다. 그래서 클라우드로 동기화하는 폴더처럼 노트가 가는 곳에 대화도 함께 가고, 노트 목록과 검색에는 나오지 않습니다. 노트 폴더를 정하지 않았으면 앱의 데이터 폴더에 저장합니다.
- 위치는 **AI 설정**의 대화 기록 폴더에서 **찾아보기…**로 바꾸고, **기본 위치로**로 되돌립니다.
- **기록 열기**는 지난 대화를 최근 것부터 보여 주고, 고른 대화를 이어 갑니다. **새 대화**는 새로 시작합니다.

## 12. 클라우드 저장소

클라우드 저장소는 데스크톱 앱에서만 씁니다. 노트 폴더를 S3 호환 클라우드 버킷과 맞춰 두면 여러 PC에서 같은 노트를 쓸 수 있습니다.

### 서비스 고르기

- **Cloudflare R2**를 권합니다. 10GB까지 무료이고 내려받기 요금이 없어 노트 용도로는 사실상 무료입니다. 카드를 등록해야 하지만 무료 범위 안에서는 청구되지 않습니다.
- 카드 없이 쓰려면 **Backblaze B2**를 고릅니다. 10GB까지 무료입니다.
- AWS S3, MinIO 같은 다른 S3 호환 서비스도 쓸 수 있습니다.
- 앱에서 설정하지 않고 맞추려면 노트 폴더를 Google Drive나 OneDrive 폴더 안에 둡니다. 이때는 모든 PC에 그 앱이 깔려 있어야 합니다.

가격과 한도는 바뀔 수 있으니 각 서비스의 요금 안내를 확인합니다.

### Cloudflare R2 설정

1. dash.cloudflare.com에 가입하고 **R2 Object Storage**로 가서 결제 수단을 등록합니다.
2. **Create bucket**으로 버킷을 만듭니다. 이름은 예를 들어 `my-notes`로 합니다.
3. R2 개요의 **Account Details**에서 **API Tokens → Manage → Create Account API token**을 누릅니다.
4. 권한은 **Object Read & Write**로, 버킷은 `my-notes`만 고릅니다.
5. 만들어진 **Access Key ID**, **Secret Access Key**, **Account ID**를 복사해 둡니다. Secret Access Key는 한 번만 보입니다.
6. Aurora에서 서비스를 **Cloudflare R2**로 고르고, 엔드포인트 `https://<Account ID>.r2.cloudflarestorage.com`, 리전 `auto`, 버킷 이름과 키를 넣습니다. **연결 확인**을 누른 뒤 **클라우드로 바꾸기**를 누릅니다.

### Backblaze B2 설정

1. B2 Cloud Storage에 가입합니다. 가입할 때 지역을 고릅니다.
2. **Buckets → Create a Bucket**으로 버킷을 Private로 만들고, 표시된 **Endpoint**(예 `s3.us-west-004.backblazeb2.com`)를 복사해 둡니다.
3. **Application Keys → Add a New Application Key**로 키를 만듭니다. 버킷은 방금 만든 버킷만, 권한은 Read and Write로 합니다.
4. keyID(Access Key ID)와 applicationKey(Secret Access Key)를 복사해 둡니다. applicationKey는 한 번만 보입니다.
5. Aurora에서 서비스를 **Backblaze B2**로 고르고, 엔드포인트 `https://s3.<지역>.backblazeb2.com`을 넣습니다. 리전은 자동으로 채워집니다.
6. 오래된 버전이 쌓이지 않도록 버킷의 Lifecycle 설정을 "Keep only the last version"으로 바꿉니다.

서비스 화면의 이름은 조금 다를 수 있습니다.

### Aurora에서 연결하기

1. Notes 메뉴 **저장소 설정…**을 엽니다. 상태 표시줄의 ☁ 항목을 눌러도 됩니다.
2. **로컬 폴더**(기본값, 지금까지와 같음)와 **클라우드 (S3 호환)** 중 **클라우드 (S3 호환)**을 고르고 연결 정보를 넣습니다.
3. **연결 확인**을 누릅니다. 버킷의 객체 수와 서비스가 동시 저장 보호를 지원하는지 알려 줍니다. 지원하지 않으면 두 PC에서 동시에 저장할 때 충돌 사본이 생길 수 있습니다.
4. **클라우드로 바꾸기**를 누릅니다. 먼저 미리 보기가 나옵니다. 올릴 파일 수와 크기, 내려받을 파일, 생길 충돌 사본, 올라갈 맨 위 폴더를 보여 주고 확인을 받습니다. 500개나 200MB가 넘으면 `노트 폴더가 맞는지 한 번 더 확인하세요.`가 함께 나옵니다.
5. 확인하면 지금 노트 폴더의 노트, 첨부(`첨부` 폴더), AI 대화 기록과 설정(`.aurora`)을 올리고, 그 뒤로 이 폴더와 버킷을 계속 맞춥니다. 그 밖의 파일(`.git`, zip 파일 등)과 `*.app`, `*.framework`, `*.bundle`, `*.download`, `__MACOSX` 폴더는 올리지 않습니다. 100MB가 넘는 파일은 건너뜁니다.
6. 다른 PC에서는 빈 노트 폴더를 고른 뒤 같은 연결 정보를 넣고 **클라우드로 바꾸기**를 누릅니다. 클라우드의 파일을 모두 내려받습니다.

- 비밀 키는 OS 키체인으로 암호화해 둡니다.
- **로컬로 바꾸기**를 누르면 맞추기를 멈춥니다. 파일은 그대로 남습니다.
- 연결 정보를 바꾸려면 로컬로 바꾼 뒤 다시 클라우드로 바꿉니다.
- 클라우드를 쓰는 중에 노트 폴더를 바꾸면(메뉴 **노트 폴더 바꾸기…**, 사이드바 아래 폴더 경로, 저장소 설정의 버튼) 먼저 묻습니다. 새 폴더를 고르면 클라우드 연결이 끊기고 로컬로 바뀝니다. 폴더 고르기를 취소하면 연결은 그대로 남습니다.
- 새 폴더를 맞추려면 저장소 설정에서 다시 **클라우드로 바꾸기**를 누릅니다.

### 맞추는 방식

- 저장하면 3초쯤 뒤에 저장한 파일만 올립니다.
- 클라우드와 전체를 비교하는 때는 앱을 켤 때, 창으로 돌아올 때(30초에 한 번까지), 5분마다, **지금 맞추기**를 누를 때입니다.
- 앱을 끌 때는 마지막으로 맞춘 뒤 저장한 파일을 올립니다.
- 맞추면서 파일을 지우지는 않습니다. 한 PC에서 지운 파일은 클라우드나 다른 PC에서 다시 돌아오므로, 지우려면 모든 곳에서 지웁니다.
- 두 PC가 같은 파일을 다르게 고쳤으면 둘 다 남깁니다. 다른 PC의 내용이 원래 이름을 갖고, 이 PC의 내용은 `이름 (충돌 <기기 이름> 10-21 0905).md` 같은 이름으로 저장됩니다.
- 열린 탭 중 고치지 않은 탭은 새 내용으로 저절로 다시 읽습니다. 고친 탭은 그대로 두고, 저장할 때 덮어쓸지 묻습니다.
- 클라우드에서 받은 내용으로 탭을 바꾸면 그 탭의 되돌리기 기록을 지웁니다. ⌘Z로 예전 글이 잘못 돌아오지 않게 하려는 것입니다.
- 내려받은 파일은 크기와(알 수 있으면) MD5를 확인한 뒤에만 기존 파일을 바꿉니다.
- 새 노트를 만들 때 같은 이름의 파일이 이미 있으면(다른 PC에서 막 받은 경우 등) 덮어쓰지 않고 그 파일을 엽니다.
- 상태 표시줄에 지금 상태가 보입니다.
  - `☁ 맞춤 09:05`는 그 시각에 맞췄다는 뜻입니다.
  - `☁ 맞추는 중 12/40`은 맞추는 중이라는 뜻입니다.
  - `☁ 오프라인`은 서버에 닿지 않는다는 뜻입니다. 다음 차례에 다시 해 봅니다. 30초 동안 답이 없는 서버도 오프라인으로 봅니다.
  - `☁ 오류`는 누르면 자세한 내용이 나옵니다.
  - `☁ 맞춤 09:05 · 3개 건너뜀`은 맞추지 않고 건너뛴 파일이 있다는 뜻입니다. 커서를 올리면 목록이 나오고, 저장소 설정에서도 볼 수 있습니다.
- 건너뛰는 까닭은 대소문자만 다른 이름, 100MB가 넘는 파일, 서버에 유니코드 형태만 다른 같은 이름이 둘 있는 경우, 여러 번 다시 해도 맞추지 못한 경우 등입니다.

## 13. 알아둘 점

- 파일은 UTF-8로 읽고 씁니다.
- 파일을 연 뒤 Aurora 밖(다른 앱, 또는 클라우드로 맞춘 다른 기기)에서 바뀌었으면, 저장할 때 **덮어쓰기**와 **취소** 중 고르라고 묻습니다. **취소**를 누르면 다른 이름으로 저장하거나 비교해 볼 수 있습니다.
- 예전 이름은 Quire, 그 전에는 TextBench입니다. Aurora를 처음 실행하면 예전 앱의 노트 폴더 설정과 단축키를 옮겨 옵니다.
- 미리보기의 일반 웹 링크는 기본 브라우저(웹 버전은 새 탭)로 열립니다.
- 웹에서 끌어다 놓아 연 파일은 원래 위치를 알 수 없어 덮어쓸 수 없습니다. 다른 이름으로 저장을 씁니다.
