# Aurora 사용설명서

Aurora는 텍스트 편집, 두 파일 비교, 마크다운 업무 노트를 한 곳에서 하는 앱입니다. 맥, 윈도우, 웹 브라우저에서 씁니다. 노트는 평범한 `.md` 파일이라 옵시디언으로도 열 수 있습니다.

이 문서의 단축키는 맥 기준입니다. 윈도우와 리눅스에서는 ⌘ 대신 Ctrl, ⌥ 대신 Alt를 누릅니다.

## 1. 설치와 실행

### 맥

1. `/Applications/Aurora.app`을 엽니다. Launchpad나 Spotlight에서 "Aurora"로 찾아도 됩니다.
2. 새로 빌드하려면 프로젝트 폴더에서 `npm run dist`를 실행합니다. `release/` 폴더에 `.app`과 `.dmg`가 생깁니다.
3. 서명하지 않은 앱이라 다른 맥에서 처음 열 때는 Finder에서 우클릭한 뒤 "열기"를 고릅니다.

### 윈도우

1. 맥에서 `npm run dist:win`을 실행하면 `release/` 폴더에 `Aurora Setup 0.1.0.exe`(설치 파일)와 `Aurora-0.1.0-win.zip`(설치 없이 실행)이 생깁니다.
2. 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 "추가 정보"를 누른 뒤 "실행"을 누릅니다.
3. 윈도우에는 메뉴 막대가 없습니다. 탭 막대 맨 왼쪽의 ☰ 버튼으로 메뉴를 엽니다.

### 웹

1. 프로젝트 폴더에서 `npm run dev:web`을 실행하고 터미널에 나온 주소를 브라우저로 엽니다.
2. 서버에 올리려면 `npm run build:web`으로 만든 `dist/` 폴더를 그대로 올리면 됩니다.
3. 노트 폴더 기능은 크롬과 엣지에서만 됩니다. 사파리와 파이어폭스에서는 파일을 하나씩 열고, 저장하면 내려받기로 저장됩니다.
4. 메뉴는 탭 막대 맨 왼쪽의 ☰ 버튼입니다.

## 2. 노트 폴더 정하기

- 노트 기능을 처음 쓸 때 노트를 모아 둘 폴더를 고릅니다. 나중에 바꾸려면 메뉴의 **Notes → 노트 폴더 바꾸기…**를 누르거나 사이드바 맨 아래 경로를 누릅니다.
- 옵시디언 vault 폴더를 골라도 됩니다. 같은 파일을 함께 씁니다.
- 노트 폴더 아래 모든 `.md` 파일을 읽습니다. `.`으로 시작하는 폴더(`.obsidian`, `.git`)와 `node_modules`는 건너뜁니다. 다운로드 폴더처럼 파일이 아주 많은 곳은 느려질 수 있으니 노트 전용 폴더를 권합니다.
- 웹에서는 브라우저가 폴더 접근 권한을 묻습니다. "파일 수정 허용"을 눌러야 저장할 수 있습니다. 다음에 열 때 권한을 한 번 더 물을 수 있습니다.

## 3. 매일 쓰는 흐름 (데일리 노트)

1. **⌘T**로 오늘 노트를 엽니다. 노트 폴더의 `daily/YYYY-MM-DD.md`로 저장됩니다.
2. 새 노트를 만들 때 가장 최근 노트의 "오늘 할 일"에서 체크한 일은 "어제 한 일"로, 체크하지 않은 일은 하위 항목과 함께 "오늘 할 일"로 넘어옵니다. 지난 노트는 고치지 않습니다.
3. 사이드바는 처음부터 켜져 있습니다. 탭 막대 왼쪽의 사이드바 버튼이나 **⌘B**로 숨기고 다시 켭니다. 달력에서 날짜를 누르면 그날 노트를 열거나 만듭니다. 점이 찍힌 날은 노트가 있는 날입니다.
4. 할 일 줄에서 **⌘Enter**를 누르면 체크박스가 토글됩니다.
5. 오른쪽 마크다운 미리보기도 처음부터 켜져 있습니다. **⌘⇧V**로 끄고 켭니다.

### 이미지·영상·파일 첨부

- 화면 캡처처럼 클립보드에 있는 이미지를 노트에서 **⌘V**(윈도우는 Ctrl+V)로 붙여 넣으면, 노트 파일이 있는 폴더 안에 `첨부` 폴더를 만들어 `Pasted image 20261020081530.png` 같은 이름으로 저장하고 커서 자리에 `![](<첨부/Pasted image ….png>)`를 넣습니다.
- 파인더·탐색기에서 이미지, 영상, 오디오, PDF, 오피스 문서를 노트 편집기 위로 끌어다 놓아도 같은 `첨부` 폴더에 복사하고 링크를 넣습니다. 같은 이름이 있으면 번호를 붙입니다.
- 미리보기에서 이미지는 바로 보이고, 영상과 오디오는 그 자리에서 재생됩니다. 그 밖의 파일은 누르면 기본 앱으로 열립니다.
- 링크가 노트 기준 상대 경로라서 노트와 `첨부` 폴더를 함께 옮기면 첨부도 따라갑니다. 옵시디언, 타이포라, 깃허브에서도 그대로 보입니다.
- 엑셀이나 웹 페이지처럼 글과 그림을 함께 복사한 경우는 글을 붙여 넣습니다.
- 저장하지 않은 새 탭에도 붙여 넣을 수 있습니다. 첨부는 탭이 들고 있다가(미리보기에는 바로 보입니다) 탭을 저장할 때 노트 옆 `첨부` 폴더에 함께 저장됩니다. 그 사이 링크를 지운 첨부는 저장하지 않고, 같은 이름 파일이 이미 있으면 번호를 붙이고 링크도 그 이름으로 고칩니다.

## 4. 노트끼리 연결하기

- 본문에 `[[`를 치면 노트 이름 목록이 뜹니다. 고르면 `[[프로젝트 A]]`처럼 들어갑니다.
- 링크를 따라가려면 링크 위에서 **⌘클릭**(윈도우는 Ctrl+클릭)하거나, 커서를 링크에 두고 **⌘⌥Enter**를 누릅니다. 미리보기에서는 링크를 그냥 누르면 됩니다.
- 아직 없는 노트 이름은 점선 밑줄로 보입니다. 따라가면 그 이름으로 새 노트가 노트 폴더 맨 위에 만들어집니다.
- `[[노트#제목]]`은 그 제목 위치로 갑니다. `[[노트|보일 이름]]`은 다른 이름으로 표시합니다.
- 같은 이름의 노트가 여러 폴더에 있으면 지금 노트와 가까운 폴더의 노트, 그다음 경로가 짧은 노트로 갑니다. 정확히 가리키려면 `[[work/회의록]]`처럼 폴더를 붙입니다.
- 본문에 `#업무`, `#업무/회의`처럼 쓰면 태그가 됩니다. 공백 뒤나 줄 맨 앞에 있어야 하고, 숫자로만 된 `#123`은 태그가 아닙니다.

## 5. 사이드바의 네 칸

- **노트**는 데일리 노트를 뺀 노트를 폴더별로 보여 줍니다. 오른쪽 숫자는 그 노트를 링크한 노트 수라서, 목차 노트나 자주 언급되는 주제 노트가 눈에 띕니다. 맨 위 버튼 세 개로 노트를 만듭니다. **+ 날짜**는 오늘 데일리 노트를 열고, **+ 주제**와 **+ 목차**는 이름을 물어 `주제/`, `목차/` 폴더에 틀(`#주제`·`#목차` 태그와 기본 제목)을 넣은 노트를 만듭니다. Notes 메뉴의 "노트 저장 위치…"에서 날짜·주제·목차 노트를 둘 폴더를 전체 경로로 정합니다. **찾아보기…**로 폴더를 고르거나 경로를 직접 적습니다. 폴더는 노트 폴더 안에 있어야 링크와 검색에 잡히므로, 바깥 폴더를 쓰려면 노트 폴더부터 바꿉니다(웹은 경로를 직접 적습니다). 기본값은 `daily`, `주제`, `목차`이고, 설정은 노트 폴더의 `.aurora/folders.json`에 저장됩니다. 폴더를 바꿔도 이미 있는 노트는 옮기지 않습니다. `공부/Electron`처럼 폴더를 적으면 그 폴더에 만들고, 이미 있는 노트면 그 노트를 엽니다.
- **백링크**는 지금 노트를 `[[ ]]`로 가리키는 곳(링크된 언급)과, 링크 없이 노트 이름만 적힌 곳(링크 안 된 언급)을 보여 줍니다. 항목을 누르면 그 줄로 갑니다.
- **태그**는 태그별 노트 수를 보여 줍니다. 중첩 태그는 들여 써서 보이고, 누르면 그 태그로 전체 검색을 합니다.
- **할 일**은 모든 노트의 안 한 체크박스를 노트별로 모아 보여 줍니다. 체크하면 그 노트 파일에 바로 반영됩니다. 그 노트가 탭으로 열려 있으면 탭 내용만 바뀌므로 저장해야 합니다.

## 6. 찾기

### 빠르게 열기 (⌘P)

- 노트 이름이나 경로 일부만 쳐도 찾습니다. 글자가 띄엄띄엄 맞아도 됩니다.
- 검색어가 비어 있으면 열린 탭과 최근에 고친 노트가 먼저 나옵니다.
- **Enter**는 고른 노트를 열고, **⇧Enter**는 입력한 이름으로 새 노트를 만듭니다.

### 전체 검색 (⌘⇧F)

공백으로 나눈 조건을 모두 만족하는 노트와 줄을 찾습니다. 아래 형식을 섞어 쓸 수 있습니다.

```
배포 확인          두 단어가 모두 있는 노트
"배포 확인"        정확히 이 문구
배포 -리뷰         배포는 있고 리뷰는 없는 노트
tag:#업무          #업무 태그 (하위 태그 #업무/리뷰 포함)
path:daily         경로에 daily가 들어간 노트
file:회의          파일 이름에 회의가 들어간 노트
task:배포          배포가 들어간 할 일 (한 일, 안 한 일 모두)
task-todo:배포     안 한 할 일 중 배포가 들어간 것
task-done:리뷰     끝낸 할 일 중 리뷰가 들어간 것
/\d단계/           정규식
```

## 7. 그래프 (⌘⌥G)

- 노트를 점으로, 링크를 선으로 그립니다. 연결이 많은 노트일수록 점이 큽니다. 없는 노트로 가는 링크는 흐린 점으로 보입니다.
- 점을 끌어 옮기고, 휠로 확대·축소하고, 빈 곳을 끌어 화면을 옮깁니다.
- 점에 마우스를 올리면 연결된 노트만 강조되고, 누르면 그 노트가 열립니다.
- "현재 노트 주변만"을 켜면 그래프를 열 때의 노트에서 2단계까지만 보입니다. "태그 보기"를 켜면 태그도 초록 점으로 그립니다.
- **Esc**나 **⌘⌥G**로 닫습니다.

## 8. 편집 도구

- **탭.** ⌘N 새 탭, ⌘O 열기, ⌘S 저장, ⌘⇧S 다른 이름으로 저장, ⌘W 탭 닫기입니다. 창에 파일을 끌어다 놓아도 열립니다. 저장하지 않은 탭은 이름 앞에 ● 표시가 붙습니다.
- **열 선택과 멀티 커서.** ⌥⇧ 드래그로 박스 모양 선택을, ⌥클릭으로 커서를 더합니다.
- **번호 넣기 (⌘⌥N).** 커서마다, 또는 여러 줄을 선택했으면 줄마다 번호를 넣습니다. 시작값, 증가값, 0 채우기를 고릅니다.
- **JSON·XML 정리 (⌘⌥J, ⌘⌥X).** 선택한 부분이 있으면 그 부분만, 없으면 문서 전체를 정리합니다. 압축은 메뉴의 Tools에 있습니다.
- **보기.** ⌥Z 줄 바꿈, 메뉴의 View에서 공백 문자 표시를 켜고 끕니다.

## 9. 비교

- **⌘⌥D**는 현재 탭과 다른 탭을, **⌘⌥V**는 현재 탭과 클립보드를 비교합니다. 디스크의 두 파일 비교는 메뉴의 Compare에 있습니다.
- 원본으로 삼을 탭에서 **⌘1**을 누르고 다른 탭으로 옮긴 뒤 **⌘⇧C**를 누르면 원본(왼쪽)과 현재 탭(오른쪽)을 비교합니다.
- **F7**과 **⇧F7**로 다음·이전 차이로 이동하고, **Esc**로 닫습니다.
- 위쪽 막대에서 공백 무시와 대소문자 무시를 켜고 끕니다. 대소문자 무시를 켠 동안에는 소문자 사본끼리 비교하므로 편집할 수 없습니다.

## 10. 단축키 바꾸기

1. **⌘,**로 단축키 설정을 엽니다. 윈도우와 웹에서는 ☰ 메뉴에도 있습니다.
2. 바꿀 기능의 키 칸을 누르고 원하는 조합을 누릅니다. 다른 기능이 쓰던 키면 그 기능에서 떼어 옵니다.
3. 글자 키는 ⌘, ⌃, ⌥(윈도우는 Ctrl, Alt) 중 하나와 함께 눌러야 합니다.
4. 데스크톱 앱은 설정 폴더의 `config.json`에, 웹은 브라우저에 저장됩니다.

웹에서는 브라우저가 먼저 가로채는 키가 있습니다. 크롬의 ⌘T(새 탭), ⌘N(새 창), ⌘W(탭 닫기)는 Aurora까지 오지 않으므로 단축키 설정에서 다른 키로 바꿔 쓰거나 ☰ 메뉴를 씁니다.

## 11. 알아둘 점

- 파일은 UTF-8로 읽고 씁니다.
- 예전 이름은 Quire, 그 전에는 TextBench입니다. Aurora를 처음 실행하면 예전 앱의 노트 폴더 설정과 단축키를 옮겨 옵니다.
- 미리보기의 일반 웹 링크는 기본 브라우저(웹 버전은 새 탭)로 열립니다.
- 웹에서 끌어다 놓아 연 파일은 원래 위치를 알 수 없어 덮어쓸 수 없습니다. 다른 이름으로 저장을 씁니다.
